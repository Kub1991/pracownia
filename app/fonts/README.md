# Local fonts

Inter and Unbounded are loaded with `next/font/local` so production builds do not
depend on Google Fonts CSS responses. The variable fonts include Polish glyphs.
Keep the accompanying SIL Open Font License files when distributing the fonts.

Sources (downloaded 2026-10-29):
- https://github.com/google/fonts/tree/main/ofl/inter
- https://github.com/google/fonts/tree/main/ofl/unbounded

Inter uses its default optical size; the site's existing CSS variables and font
families remain unchanged.
